# 美股收盘日报｜2026-11-17

## 0. 今日一句话总结

美股周二（11月17日）在英伟达财报前夜再度走弱，道指跌 848.75 点（-1.64%）至 50,759.42，标普500 跌 1.03% 至 7,340.53（7月底以来最低收盘），纳指跌 0.74% 至 24,328.38（盘中一度跌 2.1%，创约七个月新低），三大指数连续第四个交易日下跌。驱动因素不是盈利，而是利率：10年期美债收益率升至 5.118%、30年期 5.472%，市场已开始计价 12 月加息 25bp，美元指数升至 103.6（2025 年初以来最高）。结构上是典型 risk-off：NYSE 下跌股 1,924 只对上涨股 700 只，新低 362 对新高 20；唯一逆势的是半导体（SOX +0.34%）与光通信（COHR +3.65%、LITE +2.56%），软件则再度崩塌（IGV -3.29%，CRM -9.45%）。一句话判断：这是一次由贴现率上行触发的估值收缩，而非景气度逆转——盘后英伟达 Q3 营收 1,158 亿美元（同比 +103%）、EPS 2.68 美元超预期并追加 1,500 亿美元回购，股价盘后涨约 2.3%，短线情绪有望修复，但 5% 以上的 10 年期收益率仍是压制估值的硬约束。

## 16. 行业/技术趋势独立分析

本周最值得记录的结构性变化，是"AI 资本开支的确定性"与"AI 应用层商业模式的不确定性"首次被市场同时定价。英伟达单季营收 1,158 亿美元、同比 +103%，并追加 1,500 亿美元回购，说明算力侧需求仍在上行；但同一时间，Salesforce 跌 9.45%、ServiceNow 跌 6.51%、IGV 一个月跌 10.5%，市场在用脚投票：AI 把预算从"按 seat 收费的 SaaS"转移到"按 token 计费的推理"。这不是情绪，是商业模式的真实迁移——seat-based 定价在 agent 时代天然通缩。

第二条线是供给侧的本地化。美国收紧对中国光技术的进口限制，直接推升 COHR/LITE，说明光互联已成为与先进制程同等重要的战略环节，光模块/光器件的国产替代与美系替代会同时加速。

第三条线是电力约束。GEV/PWR/VRT 逆势上涨，而 OKLO/FLNC/IREN 下跌，反映市场开始区分"有订单的电力设备"与"只有故事的能源叙事"。AI 的瓶颈从芯片转向电力和并网，这是未来 2–3 年最确定的产业约束。

独立判断：算力需求（趋势）与应用层估值（情绪+真实迁移混合）需要分开看。市场当前把软件的下杀归因于利率，但我认为其中至少一半是 AI 对订阅制的结构性侵蚀——这部分不会随利率回落而修复。可能被错误定价的是半导体：在需求同比翻倍的情况下，SOX 一个月跌 15.8%、NVDA 较 50 日均线低 26.6%，定价的是"资本开支见顶"预期，而非当期业绩。

### 16.1 数据基建启发（数据库/容量规划视角）

推理成本下行 + agent 常态化，正在把数据基础设施的瓶颈从"训练"搬到"会话与轨迹"。本轮财报里最容易被忽略的信号是 NVDA 数据中心收入同比 +103% 且 Q4 指引超预期——这意味着推理侧（而非训练侧）的算力消耗在放量。推理放量的直接后果是三类数据爆炸：① agent 会话与工具调用轨迹（半结构化、超长、需要按 trace 检索）；② 检索增强产生的向量与原文双份存储；③ 可观测性日志（prompt/response/token 计量），其增速通常比业务请求快 3–5 倍。

选型上的推论：向量检索正在从独立引擎下沉到主库（Postgres+pgvector、以及各云厂商的托管向量索引），原因是"跨库一致性与运维成本"的痛感已超过"专用向量库的召回优势"；混合检索（BM25 + 向量 + 结构化过滤）成为默认范式，倒逼数据库同时具备倒排索引与 ANN 索引。OLAP/OLTP 边界也在移动：会话元数据走 OLTP，token 计量与成本归集走列存/湖仓，按 trace_id 关联。容量规划上，建议按"每活跃 agent 每日 5–20MB 轨迹"做粗算，优先用分层存储（热表 + 对象存储冷层 + 列存汇总）而不是一味扩容向量库；缓存分层（prompt 前缀缓存、检索结果缓存、embedding 缓存）对成本的边际收益，通常高于换更大的实例。
