## 16. 行业 / 技术趋势独立分析

昨夜的价格结构讲了一个非常清晰的故事：**市场正在把"AI 受益"的定价从"算力芯片"重新分配到"算力的物理瓶颈"**。光模块（AAOI +15.6%、LITE +10.7%、COHR +9.3%）、存储（MU +11.9%）、定制 ASIC（MRVL +9.3%）、半导体设备（LRCX/AMAT/KLAC 均涨 5–6%）四条线同步暴涨，而英伟达只涨 2.87%、微软跌 2.26%。这不是"AI 行情回来了"，而是**AI 行情的定价重心从"谁卖铲子"转向"谁的铲子不够用"**。

产业层面的结构性变化是真实的：当模型规模扩张的边际收益递减、推理占比快速上升时，瓶颈会从 FLOPS 转移到**内存带宽、互联带宽和电力**。HBM 涨价、光模块从 800G 向 1.6T 迁移、CPO（共封装光学）路线加速——这些都是可验证的工程趋势，不是情绪。**但也必须区分**：光模块个股距 50 日线仍有 -26% 到 -38%，说明过去两个月的下跌已经把"增速放缓"定价进去了，昨夜的暴涨是**空头回补 + 估值修复**，而非新订单落地。这是情绪与趋势的分界线。

市场可能的定价偏差在两处。**第一处是软件**：IGV RSI 37、NOW RSI 13.4、ADBE RSI 16.3，市场在定价"AI Agent 会摧毁 seat-based 订阅"。这个方向是对的，但节奏错了——企业级替换的周期是 3–5 年，而不是 2 个季度，短期存在过度悲观。**第二处是 AI 电力**：在半导体暴涨 5.66% 的日子里，GEV 只涨 1.41%、NLR 只涨 1.10%。如果 AI 资本开支真的在加速，电力是唯一的物理约束，这个滞涨是不合理的。这两个方向构成了未来 1–2 个季度最值得跟踪的"错误定价"。

对工程的启示很直接：**推理成本下降正在把 Agent 从 demo 推向生产**，而生产环境的成本结构里，向量检索、上下文存储、日志与轨迹的占比会快速超过模型调用本身。这意味着后端架构的重心将从"API 编排"转向"数据层"——这与昨夜存储与光通信的暴涨是同一件事的两面。

### 16.1 数据基建启发（数据库 / 容量规划视角）

从本周的价格与产业信号看，数据基建层面有三个可操作的判断。

**第一，容量规划要按"推理量"而非"用户量"重估。** Agent 的生产化带来的是**每次交互的写放大**：一次用户请求会产生多轮工具调用、每轮都有 prompt/response 全量日志、以及可选的 embedding 与轨迹快照。经验上，一个日活 10 万的 Agent 产品，其日志与轨迹的年增量在 PB 量级，远超同规模 SaaS。这意味着**对象存储 + 列存的冷热分层**必须从第一天就设计，而不是等爆炸了再补。HBM/存储涨价的产业信号，本质上是这条需求曲线在硬件端的映射。

**第二，向量检索正在从"独立引擎"下沉为"主库的一个索引类型"。** 当检索规模从百万级走向十亿级、且需要与业务表做混合检索（metadata filter + 语义召回 + 全文 BM25）时，维护一套独立的向量数据库会带来一致性、双写延迟和运维成本三重负担。Postgres 的 pgvector / pgvectorscale、以及支持 HNSW + 倒排混合检索的主库方案，在中等规模（<5 亿向量）下已经够用。**判断标准**：如果业务需要强一致的事务性写入 + 混合过滤，留在主库；如果只需要纯 ANN 且规模 >10 亿，再考虑专用引擎。

**第三，OLAP 与 OLTP 的边界会因为 Agent 分析需求而重新划线。** Agent 的可观测性（哪一步工具调用最慢、哪个 prompt 版本成功率低）本质是**高基数、时序、半结构化**的分析负载，这类查询打在 OLTP 主库上必然拖垮在线服务。合理的分层是：OLTP 存状态，CDC 到列存（ClickHouse / Doris / Iceberg），分析走列存。**缓存分层**也要重新设计——Agent 的 prompt 前缀缓存（provider 侧）与应用侧的语义缓存（向量相似度命中）是两层不同机制，混为一谈会导致成本模型完全失真。

**本周无显著数据基建信号的部分**：数据库厂商的融资、并购、版本发布在本周的公开信息中未出现足以改变格局的事件，故不做推测。
