## 16. 行业/技术趋势独立分析

本周最结构性的变化不是股价，而是**AI 资本的定价方式变了**。Anthropic 以 813 亿美元募资、83 美元定价完成史上最大 IPO，同时 CoreWeave 的债券收益率一度超过 16%——同一条产业链上，股权可以拿到极高估值，债权却要被索要垃圾债级别的利率。这个裂口说明市场并不怀疑 AI 的需求，而是怀疑「重资产算力」的现金流回收周期。NVDA CEO 辞任则把治理折价直接加到最核心的标的上：当一家公司的市值依赖于单一口径的资本开支指引时，管理层变更本身就足以触发 26% 的月度回撤。

对工程侧的启示有三点。第一，推理成本仍在快速下降，单位 token 价格的下行会继续把 agent 从「演示」推向「生产」，未来 12 个月的真实增量在应用层与工具链，而不是算力租赁层。第二，软件板块的分化（PANW/CRWD 反弹 vs CRM/NOW/DDOG 杀估值）反映的是「安全与可观测性属于刚需预算，协作与营销属于可裁预算」，采购结构的差异比 AI 叙事更能解释股价。第三，光通信（AAOI 距高点 -81.7%）与 AI 电力（FLNC -82.5%）的估值已回到「项目延期 + 融资成本上升」的悲观情形，任何一份超预期订单都会带来极大弹性，但这是交易性机会而非趋势性机会。

独立判断：情绪是「AI 见顶」，趋势是「AI 资本开支从普涨转向分化」。市场可能定价偏差的地方在于把 NVDA 的治理事件当成行业需求见顶——这两件事并不等价，网络设备（ANET 今日 +4.0%、站上 50 日线）已经给出了反证。

### 16.1 数据基建启发（数据库/容量规划视角）

从容量规划角度看，本轮 AI 估值压缩反而强化了三个数据侧趋势。其一，推理单价下行会直接放大**轨迹数据的体量**：agent 每次会话产生的 prompt/response/工具调用日志，量级是传统 API 日志的 5-10 倍，且需要可回放（用于评测与审计），这意味着对象存储的冷热分层与「按会话分片」的写入模式会成为默认设计。其二，向量检索正在从独立引擎下沉到主库：当 embedding 规模从百万级升到十亿级、且要求与业务表做混合检索（filter + ANN）时，维护独立向量库的运维成本开始高于在主库上加 HNSW/DiskANN 索引，Postgres + pgvector 或列存 + IVF-PQ 的组合会更常见，代价是接受召回率与写入放大的权衡。其三，AI 数据面正在分裂成两条管道：一条是 OLTP 式的会话状态（低延迟、强一致、按 session 分片），一条是 OLAP 式的特征与评测聚合（列存、批量导入、容忍分钟级延迟）。用同一套系统硬扛两者，是当前很多 agent 平台成本失控的根因。

工程建议：① 会话存储优先选支持 TTL 与压缩的 KV/宽表，不要用关系库存整段对话；② 向量索引按「热数据内存 HNSW + 冷数据磁盘 ANN」分层，避免全量驻留内存；③ 评测与可观测数据走列存（ClickHouse/DuckDB/湖仓），与线上库物理隔离；④ 容量模型里显式计入「重放成本」——一次全量回放可能就是数十 TB 的扫描。本周无更多来自厂商的存储侧硬信号，以上为基于现有价格与架构趋势的推断。
