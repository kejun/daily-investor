## 0. 今日一句话总结

昨夜美股是一场典型的"指数分化、内部大搬家"：道指涨 1.02% 至 52,495.88 点、逼近历史高位，罗素 2000 涨 1.65%，而纳指几乎收平（-0.02%）、纳指 100 跌 0.13%，费城半导体指数再跌 0.29%。驱动因素是资金从"AI 算力 + 杠杆新云"继续撤出，转向金融、消费、医疗与中小盘——费半距 52 周高点已回撤 22.9%，RSI 仅 26.7，处于技术性超卖；而道指 RSI 已达 75.2。VIX 回落 6.13% 至 17.31，说明这不是系统性风险，而是**结构性轮动**。最值得关注的一条线是 10 年期美债收益率仍高达 5.12%、30 年期 5.43%，高利率对长久期 AI 资产的估值压制尚未解除。**判断：指数层面风险可控，但 AI 链条的"去杠杆 + 去拥挤"仍在进行中，不宜在费半反弹第一天就断言见底。**

## 16. 行业/技术趋势独立分析

本周最值得记录的结构性变化，不是指数涨跌，而是**AI 产业的融资结构正在被重新定价**。三条线索：其一，CoreWeave 的信用风险指标创历史新高，高盛上调评级却挡不住股价下跌约 4%，说明市场已从"看订单"切换到"看资产负债表"——neocloud 模式的本质是用高杠杆买 GPU 再出租，当 10Y 在 5% 以上，这个利差生意在数学上就不再性感。其二，TSMC 交出连续第六个季度创纪录利润，却对 2027 年给出谨慎指引，这是**产业链从"产能短缺叙事"进入"需求可见度叙事"的标志**：好业绩不再自动等于好股价，市场开始要求"下一年的确定性"。其三，Meta 的 Agent 产品 "Muse" 首份季报即将披露，这是"AI 从 capex 走向 opex/收入"的关键验证点——如果 Agent 订阅收入能见度提升，估值逻辑会从"卖铲子"切换到"卖服务"，这才是真正能对抗高利率的现金流。

对数据库与前端的工程启示：推理成本下降 + Agent 普及，正在把"每次会话都产生一份持久化轨迹"变成默认架构。这意味着三类数据会指数级膨胀——会话状态（session/thread）、工具调用轨迹（trace/span）、以及检索用的向量与原文（chunk + embedding）。工程上的直接后果是：向量检索必须下沉到主库（Postgres + pgvector / 混合检索 BM25+ANN），否则"数据库 + 向量库"双写带来的一致性成本会吃掉 Agent 的毛利；前端则从"请求-响应"转向"流式事件 + 可中断的会话状态机"，UI 需要原生支持部分结果、工具中间态与回滚。这两点会在未来 2-3 个季度成为 Agent 产品的分水岭。

独立判断：**"AI 电力/核电"是情绪，"AI 推理成本下降 + Agent 存储"是趋势**。市场当前的定价偏差在于——把 neocloud 的杠杆风险错误地外推到了整个 AI 硬件链（COHR -27%/月、LITE -16%/5 日），而真正受益于推理普及的"数据层 + 可观测性"（DDOG +13%/月、SNOW 超跌）反而被错杀。这是本轮调整里最值得逆向布局的裂缝。

### 16.1 数据基建启发（数据库/容量规划视角）

从容量规划角度看，本周释放了三个明确信号。**第一，数据规模的结构在变**：Agent 会话不是"请求-响应"式的短事务，而是长生命周期的状态机，一次会话可能产生数十到数百条工具调用记录。当并发 Agent 从"实验"走向"生产"，写入放大（write amplification）会从 QPS 问题变成**存储容量与写吞吐问题**——日志/轨迹表会成为新的"最大表"，而它天然是 append-only + 时间序的，适合列存（Parquet/Iceberg）或 TSDB 承载，而不是硬塞进 OLTP 主库。

**第二，向量检索正在下沉，混合检索成为默认**。单纯的向量库在"精确匹配 + 语义召回"混合场景下表现不如"BM25 + ANN + 重排"三段式，而 pgvector / pgvectorscale 让"向量与业务数据同库"成为可行选择：好处是事务一致性与运维简化，代价是索引构建的 CPU/内存开销与 vacuum 压力。容量规划上要预留的是**索引内存**（HNSW 图常驻）而非磁盘——这是很多团队第一次做向量化时踩的坑。

**第三，OLAP/OLTP 边界在 AI 数据面上重新划线**。可观测性（DDOG 的强势是需求侧证据）、会话轨迹、Token 计费明细，都是"高写入 + 聚合查询"的典型 OLAP 负载，但要求秒级可见性。ClickHouse / DuckDB-on-Parquet / 流式（Kafka + Flink）三条路线的取舍点在于**延迟预算**：计费与限流必须走流式实时聚合，分析与回溯可以走湖仓批处理。缓存分层（Redis 热态会话 → 对象存储冷轨迹）是成本控制的杠杆点。一句话：**AI 应用的成本结构，正在从"GPU 小时"迁移到"存储 + 检索 + 可观测性"，谁先把数据面做薄，谁就拿到毛利。**
