## 16. 行业/技术趋势独立分析

本周最值得注意的结构性变化，是 **AI 基建链条内部的分层被显著加速**。过去两个交易日，光通信（LITE -10.5%、AAOI -10.8%、COHR -7.3% 两日累计）、存储（MU 两日 -7.3%、WDC 10/12 -2.60%、STX -3.80%）、以及算力租赁/新兴核能（OKLO 年初至今 -81%、IREN -50%、APLD -34%、FLNC -63%）遭遇集中抛售；与此同时，具备重资产现金流与合同能见度的电力/电气设备（VST +2.68%、GEV +0.73%、CEG +0.65%、ETN +0.38%）逆势上涨。行业含义是：**市场正在从"AI 概念的叙事定价"切换到"AI 资本开支的现金流定价"**——即不再为"谁可能受益"付费，而为"谁已经收到钱"付费。

第二个趋势是 **AI 基础设施的成本结构开始反向影响软件**。IGV（-0.27%）明显抗跌于 SMH（-0.49%），CRM +1.75%、SNOW/PLTR 逆势或持平，而硬件链整体走弱。若推理成本下降的速度快于收入增速，价值会从"卖算力"向"用算力"迁移——这正是软件/应用层相对走强的底层逻辑，而非单纯的板块跷跷板。

**工程启示**：(1) 推理成本下降会直接压低单位 token 的经济门槛，把 agent 从"演示"推向"常驻服务"，最先受益的不是模型厂而是**能承载高频、长会话状态的中间层系统**；(2) 向量检索正在从独立服务下沉为主库的一个索引类型，混合检索（BM25 + 向量 + 结构化过滤）会成为默认能力而非加分项；(3) 前端 agent 交互范式开始从"单次问答"转向"可观测的多步执行"，对**会话状态持久化与回放能力**的要求高于对 UI 花哨程度的要求。

**独立判断**：情绪层面——OKLO/APLD/FLNC 式的杀跌属于情绪性去泡沫（这些标的基本面无变化，跌的是估值与流动性）；趋势层面——光通信/存储的走弱更可能反映**真实的需求节奏预期修正**（前期 MU 年初至今曾 +428%、LITE 曾 +535%，任何放缓信号都会被放大）。市场可能存在的定价偏差在于：**用"AI 资本开支见顶"来一次性解释硬件链回调，却同时给大盘指数 0.5% 的历史新高定价**——这两件事在逻辑上不能同时成立。要么硬件的回撤是暂时的轮动，要么指数的历史新高是脆弱的；当前 VIX 15.27 的定价，押注的是前者。

### 16.1 数据基建启发（数据库/容量规划视角）

从本周可观测的信号看，**"推理成本—数据量"的反向耦合正在成为数据基建的核心预算变量**。逻辑链条是：推理单位成本下降 → agent 常驻化 → 会话数与单会话步数同时上升 → 每用户产生的**轨迹（trajectory）数据量呈乘积级增长**，而不是线性增长。Agent 会话存储的特征与 Web 会话完全不同：单次会话内状态更新密集、需要按 step 做时间线回放、且要求"读多写多"（每次工具调用都要读写同一份会话状态）。这会把负载压力从"请求数"转移到**写放大与状态对象的版本数**上。

**存储与选型思考**：(1) **向量引擎扩容**不宜再按"文档数×维度"估算，而应按"向量数×版本数"估算——agent 的中间检索结果也会被持久化，实际写入量常是原始语料的 3–10 倍；(2) **OLAP/OLTP 边界在 AI 数据面上正在模糊**：轨迹数据既要单条低延迟读（OLTP 语义，供回放与调试），又要全量聚合分析（OLAP 语义，供成本归因与质量评估）。实践中更可行的路径是把"会话状态"放 OLTP 主库、"轨迹与指标"放列存/湖仓，通过**流式管道做近实时下沉**，而不是让一套引擎同时承担两种访问模式；(3) **混合检索（BM25 + 向量 + 结构化谓词）** 会迫使查询规划器做跨索引代价估算，缓存分层（结果缓存 / embedding 缓存 / 索引页缓存）带来的收益将超过单纯加机器；(4) 当向量检索下沉为主库的一个索引类型后，**容量规划的第一约束会从"索引大小"变成"索引重建窗口"**——因为在线业务无法承受全量重建。

**给后端/前端工程师的具体建议**：把会话状态设计成**事件日志 + 快照**而非整对象覆盖写（可把写放大降低一个量级）；为轨迹表做**按时间分区的冷热分层**，热层仅保留最近 7–14 天；给向量索引预留 **10 倍于当前数据的扩容余量**，因为 agent 场景的向量会随版本膨胀；前端侧应把"可回放的多步执行"当作一等公民来设计组件，而不是把 agent 输出当聊天消息流渲染——这直接决定了后端是否需要提供 step 级时间线查询接口。**本周无显著数据基建信号的部分**：公开披露的新增融资、数据库产品路线图变更等一手信息本次未能取得可靠信源，上述判断基于可观测的算力/推理成本趋势与 agent 负载特征推演，非厂商公告。***
