## 16. 行业/技术趋势独立分析

当日的价格行为本身就在讲一个产业故事：**Anthropic 以 1.5 万亿美元估值上市并大涨，同时英伟达、谷歌、甲骨文创 52 周新低**。这不是「AI 变差了」，而是资本市场第一次给「AI 的利润归属」重新排序——上一轮周期里，确定性利润被分配给了卖铲子的一方（NVDA、光模块、电力），模型层被认为只是烧钱方；Anthropic 的上市把定价权从「基础设施」拉回「模型与应用」，于是卖铲子的一端被系统性下调估值。这是本轮最重要的结构性变化：**AI 产业链的估值锚，正从 capex 叙事切换到 ARR/推理收入叙事**。

第二条线索在软件。Intuit 疲弱指引叠加 CRM（1 个月 -24%）、NOW（-42%）的崩塌，而 PANW/CRWD 逆势上涨，市场给出的判断很清晰：**agent 化会先吃掉「按席位收费、流程标准化」的 SaaS，但会加强「安全、身份、可观测性」的需求**。这符合工程现实——agent 大幅降低了软件使用门槛，却指数级放大了攻击面与审计需求。我认为这条分化是趋势而非情绪，未来 4-8 个季度会持续兑现。

第三条是**推理成本下降带来的需求结构变化**。推理单位成本持续下行，直接后果不是「算力需求见顶」，而是调用量爆炸——这与 2000 年代带宽成本下降后流量暴涨的逻辑一致。市场当前把「单位价格下降」误读为「总需求下降」，这可能是最大的定价偏差所在：capex 的绝对值未必下修，但**议价权会从硬件供应商转移到能规模化消耗推理的一方**。相对地，核能/铀（URA 3 个月 -37.8%）的崩塌更接近情绪出清而非趋势反转，因为电力约束是物理问题，不会因股价下跌而消失——但兑现周期以年计，不适合用季度财报节奏去交易。

对工程侧的启示：推理变便宜 → agent 从 demo 走向生产 → 单用户会话数、工具调用次数、上下文长度同时放大 → 数据面压力从「请求/秒」转向「状态/秒」。前端范式也在变：从「点击-响应」转向「意图-编排-可观测」，UI 需要暴露 agent 的中间状态与可撤销性。这些变化比股价的日内波动更值得跟踪。

### 16.1 数据基建启发（数据库/容量规划视角）

本周虽无重大数据库产品发布，但价格信号给出了明确的容量规划方向。**第一，推理成本下行会先冲击存储而不是算力**：当单次调用便宜 10 倍，调用量往往涨 30 倍，随之爆炸的是 trace、tool-call 日志、prompt/response 归档与向量切片——这些数据增长是超线性的，而它们的保留策略（热/温/冷）在多数团队仍是空白。**第二，Agent 会话存储是新的 OLTP 热点**：一次会话包含多轮消息、工具结果、状态快照与检查点，写放大远高于传统 Web 会话，需要按 session_id 分区 + 短 TTL 的热表，配合对象存储做冷归档，而不是把全部历史塞进一张宽表。**第三，向量检索正在下沉到主库**：pgvector 与业务表同库可省掉一条同步链路，代价是索引构建对 WAL 与 vacuum 的压力；规模上到亿级切片时应拆分到独立向量引擎，并采用「向量召回 + BM25/关键词」的混合检索——纯向量在专有名词与代码标识符上召回很差。

选型上，AI 数据面天然是「两条腿」：**在线服务走行存（低延迟、点查、强一致），分析/训练走列存（Parquet/Iceberg 湖仓，扫描与聚合）**，中间用流式管道（CDC → Kafka → 湖仓）打通，避免让 OLTP 库承担分析查询。缓存要分层：结果缓存（语义级，命中率最高但一致性最难）→ KV 缓存（prompt prefix cache，直接决定推理毛利）→ 对象存储（归档）。当单位推理价格继续下行，**缓存命中率会取代 GPU 利用率成为毛利率的第一变量**，这也是本周最值得提前布局的工程指标。
