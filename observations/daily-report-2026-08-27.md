## 11. 板块轮动判断

## 16. 行业/技术趋势独立分析

本周 AI 市场叙事完成了一次"预期修复"：英伟达给出 FY2028 营收增长 70% 的罕见前瞻指引，并明确"需求远大于供给"——**瓶颈从需求侧彻底转移到供给侧（TSMC 先进封装 + HBM 内存）**；与此同时 OpenAI 等自研定制芯片（ASIC）的推进，标志着行业从"单一垄断供应商"向"通用 GPU + 定制 ASIC 混合"的技术路线分化。软件端，Salesforce 与 Anthropic 的 "Claudeforce" 合作是**"AI 应用层开始大规模消化模型能力"**的标志性事件——模型从聊天工具真正进入企业工作流；Anthropic 估值 9,650 亿美元、IPO 在即，说明一级市场对"模型即平台"的定价仍在加速。网络安全是本周最大的结构性亮点：AI agent 攻击面爆发（Mythos 模型发布、OpenAI-Hugging Face 事件）把安全支出从"可选"变成"刚需"，身份安全（OKTA）与终端安全（CRWD）成为 AI agent 时代的第一批确定性受益者。**独立判断**：NVDA 70% 指引与 9,650 亿美元估值有"叙事溢价"成分（供给约束本身也是供给不足的价格信号），但软件估值修复与安全支出刚需化是**趋势而非情绪**；市场可能定价偏差在于——低估了供给约束对 AI 资本开支节奏的扰动，以及高利率环境下"只买 AI"策略的脆弱性（今日 10 个板块下跌即为预警）。

### 16.1 数据基建启发（数据库/容量规划视角）

从数据基建视角，本周释放的信号非常明确：**AI agent 规模化（Claudeforce、身份安全、安全日志）将带来数据面三大增量——身份/会话数据、安全事件日志、agent 轨迹数据**。工程启示：① **会话与轨迹存储**：Agent 交互将以远超 human-to-human 的频次产生短文本 + 结构化元数据，传统关系库与对象存储需要叠加"低成本高吞吐写入 + 分层冷热归档"（如列存 + 存储分级）设计，避免日志/轨迹直接进 OLTP 主库；② **向量检索下沉**：企业级 RAG 与 agent 记忆要求向量索引（HNSW/IVF）在库内原生支持，混合检索（向量 + 全文 + 元数据过滤）成为标配，向量引擎扩容与缓存分层（KV/GPU 内存缓存）是容量规划重点；③ **安全数据湖**：攻击面扩大意味着 SIEM/SOAR 数据规模指数增长，流式处理（Kafka/Flink 类）+ 湖仓（Iceberg/Delta 类）边界进一步模糊，"写入即分析"成为安全类 workload 的默认架构；④ **成本约束回归**：推理成本下降会推动 agent 平民化，但存储与检索成本会反向上升——容量规划必须把"单位 agent 会话的存储成本"纳入 TCO 模型。本周无显著的数据基建厂商财报级信号，以上判断基于行业叙事推演（数据源有限，标注为独立观察）。
