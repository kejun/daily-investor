- **资金流线索**：债券（TLT）大涨 + 长端收益率回落——资金从"防御/高股息"转向"久期 + 科技"；软件被减仓而硬件/光通信获加仓，呈财报周前的"确定性优先"特征。

## 11. 板块轮动判断

- **当下主旋律**：美债收益率从高位回落 + 油价暴跌 = "滞胀担忧缓解"交易。受益链条：久期资产（科技成长、房地产、公用事业）> 大宗商品（能源）> 防御（必需消费）。

## 16. 行业/技术趋势独立分析

本周 AI 产业出现两条值得注意的结构性变化：一是**光通信与存储成为 AI 硬件新主线**——LITE/COHR/AAOI 连续放量上行、SMCI 与 Cisco 合作、Raymond James 给出 2,010 亿美元服务器 CPU 空间，显示市场定价正从"GPU 单点"转向"网络/存储/系统集成"的全面算力基建，本质是推理规模扩张带来的带宽与存储需求前置。二是**核能/算力租赁（OKLO/APLD/IREN）与软件（IGV/PANW）的冰火两重天**——前者有加拿大铀供给收紧的真实催化，后者被获利了结，说明本轮行情的资金偏好仍是"物理资产"而非"软件订阅"。

对数据库/前端的工程启示：推理成本下行使 agent 应用平民化，会带来**日志/轨迹/向量数据的指数级增长**——每一项 agent 任务的思考链、工具调用、检索结果都成为新的持久化数据；向量检索正在"下沉"进主数据库（pgvector、内置向量引擎成为标配），同时混合检索（稀疏+稠密）与列存分析（OLAP）在 AI 应用数据面的边界越来越模糊。

**独立判断**：OKLO 11.5% 的脉冲更多是主题情绪（铀警告 + 财报周催化剂），其股价仍在 MA200 下方很远，追高风险大；而光通信/存储的上行有盈利与出货数据支撑，属真趋势。市场当前的定价偏差可能在软件端——IGV 是唯一站上全部均线的科技分支，若 NVDA 财报确认推理需求超预期，资金很可能从"物理资产"回摆至软件/应用，这是未来一周最值得埋伏的逆向机会。

### 16.1 数据基建启发（数据库/容量规划视角）

本周的算力叙事强化了一个容量规划信号：**推理成本下降不等于存储成本下降**。Agent 会话、轨迹日志与 RAG 向量的单位生成成本在降，但"留存什么、存多久"的成本曲线在涨——按 token 计价的日志留存正在成为新的容量科目，值得在预算中单独列项。选型上：高频轨迹检索走**向量索引+混合检索**（主库内嵌或独立向量引擎二选一，避免双写）；大规模历史轨迹用**列存湖仓**（Iceberg/Parquet）分层冷归档，热数据落缓存（Redis/分布式内存），形成"缓存-在线库-湖仓冷层"三层结构。流式管道（Kafka/Redpanda 类）在 AI 数据面的位置继续上移：推理事件流、反馈回路都要实时入湖。对后端/前端工程师的启示：不要把"向量化"当银弹——先量化每类数据的检索 QPS 与延迟 SLA，再决定用主库内置向量还是独立引擎；OLTP/OLAP 边界模糊化（HTAP）会让选型在一年内反复横跳，宁可把 schema 设计成可迁移的列族，也不要被单一厂商绑定。（说明：本周公开信息暂无显著的数据基建大事件，以上为基于算力产业信号的推断。）
