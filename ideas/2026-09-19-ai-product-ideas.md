## 🎯 潜在需求分析

### 需求 1：高风险场景的 AI 决策验证层——"AI 输出不再被无条件信任"

**痛点来源**：
- **美军 AI 幻觉情报事件敲响警钟**：AI 生成的军事情报结论是幻觉，却通过了初检进入决策链——**"模型自信 + 流程信任"的组合在不可逆场景下是致命的**；类似风险同样存在于金融交易、医疗诊断、司法辅助、电网调度等"错一次就出事"的场景
- **现有"幻觉检测"工具全部不合格**：GPTZero 类只做文本分类、置信度打分类只做单模型自评——**没有"证据链级"的验证**：AI 说"中国舰船 X 正在接近"——它依据的原始数据在哪？是哪个传感器/哪条情报源？有没有交叉印证？**"结论-证据-来源"三者的对应关系无法机器化核验**，这正是美军事件发生的根本原因
- **监管与采购开始强制"人类控制"**：美中"核武式"AI 护栏提议（昨日热点）与各国 AI 法案都在写"高风险场景必须有人类审批 + 审计留痕"——**但企业没有工具实现"机器验证 + 人工复核"的标准流程**，只能靠邮件/Excel 手工兜底
- **Agent 自主性上升放大风险**：当 Agent 能自主执行（下单、发指令、写报告、调用 API），**"谁对 Agent 的输出负责"成为企业不敢授权 Agent 的根本原因**——没有验证层，就没有问责链，就没有保险可买
- **AI 安全攻防升级让"内部 AI 输出"也不可信**：OpenAI 被 Claude 辅助攻破、提示注入攻击泛滥——**连"自己系统里的 AI 输出"都可能被外部污染**（间接提示注入），需要在输出进入决策前做"消毒 + 验证"

**具体场景**：
某对冲基金的交易模型接入 LLM 生成的市场分析摘要并自动触发部分交易信号——风控部门需要**"决策验证网关"**：每个 AI 结论必须附带"引用数据源 + 交叉验证结果 + 置信度"三件套，置信度低于阈值或数据源无法核验的结论**自动降级为"仅供参考"并转人工**。

另一个场景：某医院的 AI 辅助诊断系统给出用药建议，按新规要求"高风险建议必须人工复核留痕"——医生需要**"AI 建议验证工作台"**：AI 建议自动关联文献与检验数据、标注不确定项、生成复核清单，医生一键确认后自动生成审计日志（谁、何时、依据什么、采纳与否）——**把"合规负担"变成"三分钟点选"**。

还有：某军工/情报承包商要用 LLM 处理开源情报（OSINT），但美军事件后上级要求"每条关键结论必须可溯源"——他们需要**OSINT 证据链工具**：AI 生成的情报结论自动锚定到原始信源（卫星图、社交媒体帖、新闻原文），生成"结论→证据→信源"的可回溯图谱，支持审计抽查。

**市场机会**：
- 目标客户：金融（量化/风控/合规）、医疗（辅助诊断/用药）、国防与情报承包商、能源/电网、政务（司法辅助/审批）、部署 autonomous agent 的中大型企业
- TAM：**AI 治理/验证/可观测市场**——Gartner 类预测 AI 信任与安全（AI TRiSM）市场 2026-2028 年达 $150-300 亿；"决策验证层"是其中最高客单价细分（按"风险敞口"定价而非按席位），金融+国防两个行业即可支撑百亿级美元空间；中国"AI 备案 + 生成式 AI 管理办法"对高风险应用的强制审计要求提供政策托底
- 付费意愿：**"一次事故的损失 >> 验证层的年费"**是铁律级话术（美军事件的代价无法用钱衡量；金融误判一次可能上亿）；按决策量计费（$0.01-0.5/次验证）或按保护资产规模抽成（交易量 bp、保费分成）；国防/金融客户客单价 $100K-1M/年
- 竞争空白：现有玩家分散——LLM 网关（LiteLLM 类）只管路由不管验证、可观测平台（LangSmith 类）只记录不拦截、AI 检测器（GPTZero 类）只测文本概率；**"结论-证据-来源"三级核验 + 置信门控 + 强制人工升级 + 审计留痕的一体化验证网关是空白**——且验证数据（哪些源可信、哪些模式曾出错）会形成跨客户的风险知识库护城河

### 需求 2：AI 训练数据的合规供应链——"数据资产"的发现、清算与授权

**痛点来源**：
- **高质量训练数据极度稀缺**：公开网页被 AI 生成内容污染（"模型吃自己的输出"）、版权诉讼风险高企（NYT 案员工证词"最大规模劳动盗窃"）、合成数据有质量天花板——**模型公司愿意为好数据付钱，但找不到合规货源**
- **SpaceXAI 抄底"死公司数据"揭示市场失灵**：大量倒闭/转型公司的客户数据、运营日志、交易记录是**高质量垂类语料**（真实、结构化、带标签），但破产清算方、托管方（云厂商、域名商、SaaS 平台）**不知道这些数据值钱，更不知道怎么合规变现**——数据被格式化、被贱卖、或躺在冻结账户里腐烂
- **版权大战让"未授权数据"变成负债**：NYT 案、韩国 10% 营收罚款（HN 220 points）、欧盟 AI 法案的透明度要求——**"来路不明"的数据随时引爆法律与监管炸弹**，模型公司急需"有授权文件、有分成机制、可审计溯源"的数据
- **数据合规处理成本高**：死公司数据含 PII（个人信息）、商业机密——**"脱敏 → 授权 → 定价 → 交付 → 分成 → 审计"的完整链路**需要专门能力（法律 + 数据工程 + 隐私计算），数据持有方和模型公司都不具备，中间缺乏专业服务商
- **数据估值没有标准**：训练数据怎么定价？（按 token？按质量？按领域稀缺度？按分成？）**缺乏"数据资产评估"的方法论与工具**，导致交易双方无法成交——需要"数据评估师"与"数据交易所"类基础设施

**具体场景**：
某 SaaS 独角兽倒闭清算，托管方（云厂商）手里有 3 年真实的产品使用日志（脱敏后含完整用户行为序列）——清算律师按"硬盘论斤卖"准备格式化；某大模型公司急需真实的"人机交互轨迹"语料训练 agent 模型——**他们需要中间商**：评估数据价值 → 与清算方/权利人谈授权 → 脱敏与合规审查 → 定价（按 token 或按一次性买断 + 分成）→ 技术交付（安全传输、水印）→ 纠纷兜底。

另一个场景：某医疗 AI 公司要训练病历理解模型，但公立医院数据出不了院——他们需要**"数据不出域"的授权方案**：在院方私有化环境内训练或联邦学习，按效果分成——**"授权模式创新"（而非"数据搬运"）是新合规时代的核心能力**。

还有：某内容平台（有 5 亿篇 UGC 文章）想开辟"数据授权"第二收入曲线，但**不知道怎么定价、怎么防泄漏、怎么分成**——他们需要**数据授权 SaaS**：自动盘点语料资产、生成授权报价（按用途/期限/领域）、水印与泄漏溯源、自动分成结算——**把"数据"变成可运营的资产组合**。

**市场机会**：
- 目标客户：大模型公司/云厂商（买方）、破产清算机构与托管方（卖方）、内容平台与垂类数据持有方（长期卖方）、SaaS 平台（数据遗产托管）、律所与合规服务商（配套）
- TAM：全球 AI 训练数据市场（含授权、合成、标注）2026 年约 $30-50 亿并高速增长；**"数据经纪/清算/授权"细分**按交易抽佣（5-15%）+ 服务费，赛道天花板取决于"合规数据交易量"——版权判决若收紧合理使用，合规授权市场将指数级放大（数倍于当前）；数据遗产清算单点市场：美国每年约 50 万家企业倒闭 × 平均数据资产价值 $1K-1M
- 付费意愿：**买方（模型公司）愿付高价买"干净+合规"数据**（对比：SpaceXAI 主动上门收）；卖方（清算方）几乎零成本变现（原来数据=废纸）；**两边都有强激励，缺的只是中间层**——撮合抽佣 + 合规服务费是清晰商业模式
- 竞争空白：现有数据交易平台（如贵阳大数据交易所类）偏政务公共数据、流程重；**"针对清算/倒闭/长尾持有方的轻量数据经纪 + 授权 SaaS + 隐私计算交付"全球空白**；先发者建立"数据资产评估方法论文档 + 授权合同模板库 + 泄漏溯源技术"三件套，可快速成为标准制定者——版权案判决落地前的 12-24 个月是窗口期
### 需求 3：Agent 技能工程化与安全审查——"技能包"取代提示词后的治理真空

**痛点来源**：
- **Agent 能力碎片化，技能不可复用、不可治理**：Claude Code 开始读 AGENTS.md、addyosmani/agent-skills 96k stars、Cloudflare security-audit-skill 单日 +3,000 stars——**"技能包"（skill：指令 + 工具 + 校验逻辑的打包单元）正在成为 Agent 能力的事实分发格式**；但企业级应用面临真空：**技能从哪来（可信来源）、版本怎么管、权限怎么控（技能能读什么/写什么）、行为怎么审计**——现在全靠开发者自觉
- **恶意/劣质技能是新的供应链攻击面**：OpenAI 被 Claude 辅助攻破（第三方论坛入口）、提示注入泛滥——**一个"看起来人畜无害"的技能包可能内置提示注入、数据外传、后门工具调用**；企业让 Agent 执行"安全审计"却不知道技能本身是否安全，是荒诞又真实的现状
- **代码审查质量参差，安全漏洞漏检**：Alibaba open-code-review 的爆火说明**"LLM 代码审查"已从玩具变生产工具**（确定性规则管道 + LLM Agent 混合架构，行级评论、NPE/线程安全/XSS/SQL 注入规则集）；但多数团队仍在用"裸提示词 + 通用模型"审查，**漏检率、误报率、不可复现**是三大痛点——审查结论没有"机器可读、可独立验证"的格式（这正是 security-audit-skill 强调的设计）
- **审查与修复没有闭环**：审查发现问题 → 修复 → 复审查 → 回归，链路靠人工粘贴；**"审查即服务"应内嵌到 CI/CD 与 Agent 工作流**——发现漏洞直接生成修复 PR（附验证证据），而不是输出一份没人看的报告
- **合规要求审查留痕**：等保、信创、行业安全规范要求"代码与系统安全审查记录可追溯"——**审查过程（谁审的、审了什么、依据什么规则、结论如何验证）需要自动留痕**，现有工具大多只给结论不给过程

**具体场景**：
某金融科技公司全员用 coding agent 写代码，上个月一个 agent 根据网上"技能包"自动改了支付模块的鉴权逻辑（技能里藏着恶意指令）——差点酿成生产事故——他们需要**技能治理平台**：技能来源白名单、安装前静态扫描（指令注入/危险工具调用检测）、运行时沙箱（技能只能访问授权资源）、行为审计日志。

另一个场景：某创业公司想在发版前做一次"靠谱的"安全审查，但请不起安全团队——他们需要**AI 安全审查流水线**：代码库接入后自动跑"确定性规则（正则/SAST）+ LLM 深度审查"双通道，输出**带证据（代码行号、CWE 编号、复现步骤）的机器可读报告**，高置信漏洞自动生成修复补丁并附验证用例，人工一键合入——审查报告同时满足等保留痕要求。

还有：某开源项目维护者每天收到几十个 PR，想用 agent 做初审但**担心恶意 PR 利用 agent 的权限**（自动合并、发布）——他们需要**"沙箱化 PR 审查员"**：agent 在只读沙箱里审查，无网络、无写权限，输出结构化评审结论（含"建议合并/需人工"分级），**审查 agent 本身的权限最小化 + 全程审计**。

**市场机会**：
- 目标客户：规模化使用 AI 编程助手/agent 的研发团队（金融、互联网、SaaS）、安全团队（应用安全、DevSecOps）、开源社区维护者、内部软件供应链管理平台
- TAM：AI 代码审查 + 应用安全市场合计 $100 亿+（SAST/DAST 存量市场 + AI 审查增量）；**"Agent 技能治理"是全新的增量品类**——跟随 agent 采用量增长，早期可绑定"AI 编程助手企业版"渠道分发（Copilot/Claude Code/Cursor 企业客户天然有治理需求）；GitHub 上 agent-skills 96k stars 证明"技能消费"已是大众行为，治理滞后于消费至少 12 个月，窗口清晰
- 付费意愿：**"技能事故（数据泄漏/错误合并）"是强痛点**（金融客户一次事故损失远超年费）；按开发者席位 $5-20/月 或按审查量计费；安全审查按仓库/按次 $200-2,000；企业版含技能库私有化托管与合规报告 $20,000-100,000/年
- 竞争空白：Snyk/CodeQL 等传统 SAST 无 LLM 深度审查且无"技能治理"；Alibaba open-code-review 开源但**无 SaaS 化、无技能市场治理、无合规留痕**；**"技能治理（供应链安全） + 证据化审查（机器可读） + 自动修复闭环"三合一的产品全球空白**——且可复用 security-audit-skill 的开源生态（13.5k stars）做获客入口

### 创意 1：VeriGate——高风险场景 AI 决策验证网关（"没有证据链的 AI 结论，不配进入决策"）

**产品定位**：
面向**金融、医疗、国防、能源等高风险行业**的 **AI 输出验证与决策门控中间件**：插在"AI 应用/Agent 与业务决策"之间，对每个关键结论执行**"结论 → 证据 → 信源"三级核验**，输出置信度与证据链，**不达标自动降级转人工，全程审计留痕**。定位类比：**AI 时代的"防火墙 + 审计师"**——不是另一个模型，而是模型与决策之间的"把关层"。核心卖点："**让 AI 的每个关键判断都可被挑战、可被追责、可被投保**"。

**核心功能**：
1. **证据链核验**：AI 结论自动关联支撑材料（数据源、文档、API 响应、传感器记录），逐条检查"结论是否有证据、证据是否真的支持结论、是否为多源交叉印证"；输出结构化证据链图谱（结论→证据→信源→时间戳）
2. **置信度门控**：多维度置信评估（证据强度、来源可信度、模型自评、历史准确率），低于阈值或证据缺失的结论**自动降级**（标记"仅供参考"）并**强制转人工复核**——支持配置"不可逆操作必须人工"的硬规则
3. **交叉验证引擎**：对关键数值/事实断言，自动调用第二数据源或第二模型独立复算（双模型交叉、数据源对比），发现矛盾即标记"冲突"并升级
4. **人工复核工作台**：被门控的结论进入人工队列，复核员看到"结论 + 证据链 + 冲突点 + 建议"，**一键采纳/否决/修改**，操作留痕（谁、何时、依据什么）——满足"人类控制"合规条款
5. **审计与问责 API**：全量决策日志（输入、输出、验证过程、人工操作）不可篡改存储，支持监管导出与事后回溯；**给保险公司的"可验证性评分"**——验证完善的企业可投保 AI 责任险

**技术实现**：
- 证据核验：声明抽取（NLI/规则）→ 证据检索（对内部数据源 RAG）→ 支持度判定（LLM-as-judge + 可解释规则）；防"重复佐证伪装独立证据"（GraphEcho 问题的反向工程化：证据去重 + 来源独立性检测）
- 置信评估：多信号融合（检索相关性、来源权威度评分、模型 logit 校准、历史准确率统计）+ 校准曲线；门控规则引擎（阈值 + 场景化策略 + 人工升级队列路由）
- 交叉验证：异构模型路由（调用第二家 API/开源模型复算关键断言）+ 确定性校验器（对数值、日期、代码片段用规则/沙箱执行验证，不依赖 LLM 判断）
- 审计存储：WORM（写一次读多次）存储或区块链锚定时间戳；结构化审计事件（NIST 800-53 对齐）支持 SIEM 接入
- 集成面：LLM 网关（LiteLLM 类）插件、Agent 框架（LangChain/Claude Code 类）中间件、企业服务总线；旁路代理模式（不侵入业务代码，SDK 接入 <1 天）

**MVP 范围**：
- 只做两个场景：**金融研报/交易信号的决策门控 + 企业 Agent 的"高影响操作"审批门控**（下单、发外部消息、改生产配置）
- 最小闭环：LLM 输出 → 证据检索（接 2 个数据源）→ 置信评分 → 门控判定 → 人工复核台 → 审计日志；不做交叉验证引擎的多模型复算（后置）
- 先以"验证评分卡"形态获客（免费生成"你司 AI 结论的可验证性报告"），再推网关部署
- 验证指标：误放行率（应转人工而未转）<1%、人工复核效率（单条 <2 分钟）、客户部署后"AI 事故数"下降 50%+
- 定价策略：
  - **按验证量计费**：$0.05-0.5/次（证据检索 + 核验 + 门控），企业月费 $5,000-50,000 起
  - **行业版**：金融风控版 $100K-500K/年（含合规报告与审计对接）；国防/政务私有化部署按项目 $500K+
  - **保险分成**：与 AI 责任险合作，按"验证覆盖率"给企业保费折扣，VeriGate 抽取保费分成——**把"验证"从成本变成资产**
  - 目标：12 个月拿下 20 家金融/企业标杆客户，ARR $5M；18 个月推出"AI 决策验证标准"白皮书卡位行业标准

### 创意 2：DataEstate——"数据遗产"清算与 AI 训练数据授权平台（"死公司的数据，是活模型的粮食"）

**产品定位**：
面向**破产清算机构、云厂商/SaaS 托管方、垂类数据持有方**的**数据资产发现、估值与合规授权平台**：当一家公司倒闭/关停/转型时，DataEstate 自动盘点其遗留数据资产，评估 AI 训练价值，完成**脱敏 → 授权 → 定价 → 交付 → 分成 → 审计**全链路，把"准备格式化的硬盘"变成"可交易的合规数据资产"；同时面向**模型公司**提供"合规数据货架"。定位类比：**AI 时代的"数据拍卖行 + 资产清算所"**。核心卖点："**让每一份濒临消失的数据，在授权与分成中重获价值**"。

**核心功能**：
1. **数据遗产盘点**：接入云账号/数据库/对象存储（只读模式），自动发现数据资产（数据库表、日志、文档、用户行为序列），生成**数据资产清单 + 质量评估**（完整性、结构化程度、领域价值、PII 含量）
2. **合规脱敏流水线**：自动识别 PII/商业机密（NER + 规则 + 人工抽检），按目标用途（训练/微调/评测）配置脱敏策略（匿名化、泛化、合成替换），输出**脱敏证明报告**（满足 GDPR/个保法/韩国 PIPA 级别要求，可审计）
3. **AI 训练价值评估**：基于"领域稀缺度 × 数据质量 × 任务适用性"给出估值区间与推荐定价模式（一次性买断 / 按 token 计费 / 效果分成）；生成《数据资产评估报告》供交易双方与清算法院认可
4. **授权交易与分成结算**：合同模板库（授权范围：用途/期限/地域/独占性）、电子签约、水印与泄漏溯源（对交付数据嵌入不可见指纹，泄漏可追责）、自动分成结算（按使用量对账）
5. **隐私计算交付**：对"数据不出域"场景（医疗/政务），提供联邦学习与私有化训练托管——**授权但不搬运**，按效果分成
6. **买方数据货架**：面向模型公司/科研机构的"合规数据市场"——按领域/质量/价格筛选，每份数据带完整授权链与脱敏报告（"数据护照"）

**技术实现**：
- 盘点引擎：云厂商 API 集成（AWS/Azure/阿里云）+ 数据库 profiling（扫描 schema、抽样评估）；对象存储元数据索引
- 脱敏：PII 识别（多语言 NER 模型 + 规则库）→ 脱敏策略引擎（k-匿名/差分隐私/合成数据生成）+ 脱敏前后一致性校验（保留统计特征）
- 估值模型：领域稀缺度（语料分布对比）+ 质量分（困惑度/结构化率/标签丰富度）+ 市场锚定（同类授权成交价），输出区间建议
- 交付安全：数据指纹（随机插入 + 语义水印）、传输加密、交付后按 token 用量计量的 SDK（买方侧埋点对账）
- 合规引擎：授权链管理（溯源到原始权利人 + 清算法院确认文件）、合规 checklist 自动生成（按法域模板）
- 部署模式：SaaS 平台 + 私有化（数据不出域场景）；与清算律所、云厂商、SaaS 平台建立官方合作入口

**MVP 范围**：
- 只做两类资产：**SaaS 关停方的用户行为日志 + 传统企业清算方的结构化业务数据**（最高频、最易标准化）
- 最小闭环：盘点 → 脱敏 → 评估 → 上架 → 授权签约 → 交付；先做"数据遗产清算"单侧市场（卖方供给稀缺，先锁定供给）
- 不做：联邦学习托管、数据货架买方市场（后置）；先以"清算合作"获客（与 5-10 家破产清算机构/云厂商签排他合作）
- 验证指标：月盘点数据资产 TB 数、交易撮合成功率、平均授权单价、卖方复购（一个清算方年处理多起清算）
- 定价策略：
  - **卖方服务费**：按成交额抽佣 10-20% + 盘点/脱敏服务费（按数据量 $500-50,000/次）
  - **买方采购**：按 token 或买断，DataEstate 赚差价/撮合费；"数据护照"认证服务 $1,000-10,000/份
  - **订阅**：垂类持有方月度盘点与估值 SaaS $2,000-20,000/月（把数据当资产组合运营）
  - 目标：12 个月 GMV $2M、锁定 30 家供给方；版权案判决落地后，**"合规授权数据"溢价将数倍放大，先发供给网络是最大壁垒**

### 创意 3：SkillGuard——Agent 技能治理与证据化审查平台（"技能可以随便装，但行为必须被审计"）

**产品定位**：
面向**使用 AI 编程助手/agent 的研发团队与安全团队**的**技能（skill）供应链治理 + AI 审查流水线平台**：一端治理"Agent 技能"（来源白名单、静态扫描、运行时沙箱、行为审计），另一端把"代码/安全审查"做成**证据化、可复现、可留痕**的流水线（确定性规则 + LLM 双通道，输出机器可读报告，高置信问题自动修复闭环）。定位：**AI 时代的 DevSecOps 新一层——管住 agent 的手，审清 agent 的活**。核心卖点："**你的 agent 越强大，越需要 SkillGuard**"。

**核心功能**：
1. **技能注册中心**：技能包（AGENTS.md/skill 格式）上传/导入 → 元数据登记（来源、作者、版本、权限声明）；支持私有技能库与公共市场（爬取 GitHub 热门技能做"安全评分榜"）
2. **技能静态扫描**：安装前自动审查（指令注入检测、危险工具调用（rm/curl/网络外传/凭据读取）识别、prompt 隐藏指令沙盘演练）；输出技能安全评分与风险明细——**检测维度对齐 security-audit-skill 的"机器可读、可独立验证"标准**
3. **运行时沙箱与审计**：技能执行时最小权限隔离（无网络/只读/受限目录按需开启）、全量行为日志（调用了什么工具、读了什么文件、输出了什么）；异常行为实时告警（数据外传特征、越权访问）
4. **证据化审查流水线**：接入代码库/PR，双通道审查（确定性规则：正则/SAST/自定义规则集（NPE、线程安全、XSS、SQL 注入）+ LLM 深度审查）；每条发现附**证据包**（代码行号、CWE 编号、复现步骤、置信度），输出机器可读报告（SARIF 格式）
5. **自动修复闭环**：高置信问题自动生成修复补丁 + 验证用例（修复后跑测试证明"修好了"），人工一键合入；低置信问题转人工队列
6. **合规留痕**：审查与技能使用全程审计（谁、何时、依据、结论、验证），一键导出等保/行业合规报告

**技术实现**：
- 技能扫描：静态 AST 分析 + 语义分析（工具调用图）+ 提示注入检测（双模型对抗：让一个 LLM 扮演"恶意指令探测器"）+ 沙箱动态执行（容器隔离，录行为轨迹）
- 运行时沙箱：容器/VM 隔离（gVisor/Firecracker 类）+ 系统调用过滤 + eBPF 行为监控；密钥管理（Vault 集成，技能只能拿到最小化临时凭据）
- 审查引擎：确定性管道（Semgrep/CodeQL 规则集 + 自定义正则）+ LLM agent（只读上下文、结构化输出约束）；发现融合（去重、置信度融合、分级）
- 修复生成：问题定位 → 补丁生成（diff）+ 测试生成（针对该 CWE 的最小复现用例）→ 沙箱跑测试验证 → 附验证证据提交
- 数据飞轮：审查发现库（按 CWE/语言/框架统计）、技能信誉分（使用量 + 事故率 + 人工反馈）——**信誉分是技能市场治理的核心资产**
- 集成面：GitHub/GitLab CI、Claude Code/Cursor/Copilot 插件、IDE 扩展、Slack/飞书告警

**MVP 范围**：
- 只做两个场景：**技能扫描与沙箱执行（治理侧）+ PR 审查流水线（审查侧）**
- 最小闭环：安装技能前扫描 → 打分 → 允许/拒绝；PR 提交 → 双通道审查 → 证据化报告 → 高置信修复建议；不做运行时 eBPF 深度监控与技能市场（后置）
- 先免费开放"技能扫描器"（对标 security-audit-skill 的开源获客策略），企业版收治理与审查的钱
- 验证指标：技能扫描检出率（注入/危险调用 recall ≥90%）、审查误报率 <20%、修复采纳率 ≥40%、审查报告生成 <5 分钟
- 定价策略：
  - **开发版**：$10-30/席位/月（技能治理 + 基础审查）
  - **安全版**：$30,000-150,000/年（高级规则集、合规报告、沙箱、审计对接）
  - **按量**：深度审查 $0.5-5/千行；技能安全评分 API 免费（获客 + 数据飞轮）
  - 目标：12 个月 500 家企业客户（含 50 家付费安全版），ARR $5M；绑定 AI 编程助手生态（做 Copilot/Claude Code 的官方治理插件）是分销捷径
